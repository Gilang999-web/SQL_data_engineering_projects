# SQL Data Engineering Projects

The following repository contains a collection of SQL projects built to practice and demonstrate core Data Engineering skills using **DuckDB**, **MotherDuck**, **VS Code / Antigravity IDE**, and **Git & GitHub**.

---

## Projects

### 1. [Exploratory Data Analysis (`1_EDA`)](./1_EDA/)

An end-to-end SQL analysis of the remote **Data Engineer** job market using the `data_jobs` star-schema data warehouse.

- **Key Focus:** Multi-table `INNER JOIN`s, `MEDIAN()` salary analysis, `LN()` demand scaling, and `HAVING` aggregation filtering.
- **Queries Included:**
  - [`01_Top_demand_skills.sql`](./1_EDA/01_Top_demand_skills.sql)
  - [`02_top_paying_skills.sql`](./1_EDA/02_top_paying_skills.sql)
  - [`03_optimal_skills.sql`](./1_EDA/03_optimal_skills.sql)
- **Tools Used:** DuckDB, MotherDuck, SQL, Markdown, Git, GitHub.
